# 05A / 04B 视频输入检查与候选采用验收

日期：2026-09-20。状态：本地代码及离线验证完成；业务运行镜像未更新，真实质量待验收。

## 本批实现

- `drama_skills.review_shot_speech`统一统计对白和旁白，沿用每秒5字的粗估；准备单显示分别字数、总时长、镜头时长和机位/运镜。明显超出预算返回`VIDEO_SPEECH_OVER_BUDGET`，排队和旧同步提交均在调用模型前阻断。不改原文、不自动加长计费时长。
- Context-IR编译明确机位、运镜、人物路径的职责，动作应达到结束状态；人物参考锁定身份，不继承背景或正面站姿。缺阶段/场景图给予提示，空间语义冲突仍需人工核对。
- 新画面页`POST /api/projects/{project_id}/shots/{shot_id}/video-jobs`默认保存候选，候选可通过签名地址播放。`POST /api/projects/{project_id}/video-jobs/{job_id}/adopt`核对项目权限、镜头、当前模型配置、准备指纹及对象存在；事务内版本校验，采用幂等，更新资产及下游失效。
- 批量得到候选后停止继续提交，用户先播放再采用。生成失败、未知、输入过期及文件缺失不能采用；旧有效结果在采用成功前保留。
