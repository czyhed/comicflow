# 7B 迁移工具契约

状态：2026-09-22已实现并通过合成数据隔离演练。仅固定计划第1步，下一步仍为15D。源码回溯点b867b16，计划版本b940a24。见[使用说明](migration-tooling-usage-2026-09-22.md)与[验收记录](migration-tooling-verification-2026-09-22.md)。

命令行入口`scripts/migrate_data.py`提供inventory、backup、restore、verify。配置通过显式JSON文件传入，不自动加载.env、不导入应用或启动Worker/Beat；文件含连接凭据须放Git忽略的var目录。复用asyncpg、boto3、Redis、SecretCipher、PostgreSQL 16 pg_dump/pg_restore。无需新表、新框架或修改业务API。

输入：显式PostgreSQL、MinIO桶、Redis命名空间、解密密钥文件及PostgreSQL客户端命令前缀。报告输出数量、校验和、对象键/元数据、异常定位及密钥指纹，不主动写入连接凭据、故事正文、签名URL；对象键和用户元数据仍可能含私有信息。备份本身含业务和加密配置，属于私有数据；原密钥在备份目录外单独保存。

盘点：完整检查当前0004七张业务/迁移表及模型配置自增序列，记录稳定行摘要/序列状态；额外用户关系拒绝，盘点与pg客户端共享SSL策略。递归收集项目、角色和作业中所有对象键，包括objectKeys导出映射、候选及失效历史；列出仅URL/本地路径的媒体，不自动下载或补生成。复制整个专用桶，保留所有对象、Content-Type及用户元数据，逐对象SHA-256而非ETag。开启过版本控制的桶先拒绝，版本迁移另行制定。

备份：必须声明写入进程与消费者已停止；拒绝未终结图片/视频作业、活动槽、未发布outbox、未结束旧生产任务或活动会话，以及队列/未确认消息/未知Redis临时状态。声明不能代替停写，工具不会远程关闭业务进程。数据库使用只读快照并将同一快照交pg_dump；前后复核数据库及对象摘要，最后才发布完整manifest。失败只留下不完整目录，不能恢复，不清理源端。

恢复：目标标识必须显式确认且与备份源标识不同；拒绝非空库/桶、已有目标Redis命名空间、错误密钥、被篡改的备份或不支持的schema。备份文件先校验，再pg_restore事务恢复，再复制对象并校验。失败停止、保留部分目标供诊断，不自动删库/清桶或续跑任务；重新演练使用新的空目标。恢复当前schema，不顺手升级业务；后续schema变化须另做迁移及演练。

校验：源/恢复库所有表摘要、对象键/内容/元数据、模型配置全部历史的解密能力相同。Redis只分类不复制；目标命名空间须为空。不调用供应商，不生成图片/视频、不签发新生产任务。

验证：先做失败测试（引用收集、未完成作业、密钥、路径/校验/覆盖保护），再在Docker内部网络中的独立PostgreSQL/Redis/MinIO演练合成数据；宿主控制器经固定目标代理的随机回环端口访问。真实pg_dump/pg_restore及对象读写，旧有效/候选/历史资产均覆盖。使用已缓存镜像，不挂业务卷/.env或Docker socket。代理连接edge网络，宿主并非完整网络沙箱；实际只用合成配置，没有模型调用。正式服务器迁移不在本批。
