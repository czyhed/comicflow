# YouMind风格增量与轻量UI

2026-09-23。用户要求借鉴YouMind每周最热真人视频与Image 2/2.5提示词，随后补充按钮和UI轻量美化。

## 本批契约

- 输入：已有项目风格快照、新建时的预设ID、原人物/场景/镜头字段。输出：新增三种可选真人风格，继续保存完整规则快照、沿既有图片/视频链路编译。
- 新增真人纪实DV、克制悬疑摄影、电影色彩对比；原六种预设v2内容保持。风格不注入来源案例的人物、地名、对白、天气、暴力事件或固定30秒时长，不自动切模型/分辨率。
- DV拍摄特征只放在视频motion；身份参考图仍清晰、中性布光，不为纪实感破坏身份识别。场景和镜头沿用原稿时间/光源。
- Image 2/2.5继续共用实际Adapter；移除旧OpenAIImageProvider主图追加的强制3D/真实毛孔/8K/UE5词，保留用途与清晰度约束。整板版式和调用次数不改。
- UI保留原生选择器、错误重试及新项目范围；新增紧凑色彩示意与规则层级，微调主要/次要按钮、悬停/禁用/键盘焦点和减少动态效果设置。
- 失败行为：未知预设/坏快照仍拒绝；目录错误可重试，不能用空列表冒充成功。选择零业务写入/零模型调用。
- 验收：新风格经过真实图片请求组装和H3本地编译；原文/尺寸/模型保持；旧快照回归。前端build及已有浏览器交互回归，检查390px/1024px窗口和截图。

本批不部署、不启动消费者、不改数据库/素材/模型配置。完整数据与密钥迁移、Redis切换仍为后续主线。
