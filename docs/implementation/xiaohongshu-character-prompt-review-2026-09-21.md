## 这次值得修正的建议

此前强调全身主图是为了提供完整服装和体型，这仍有用；但全身图里的脸较小，文字“清晰五官”不能替代实际图像像素。整板可以同时安排一块更大的脸部区域，增强脸部资料的可读性，而不是新增第四张独立参考图片。

因此建议下一项任务4评估固定布局：**一张已确认主图 → 一次图生图 → 同一张板包含面部特写＋正面/严格侧面/背面全身 → 用户确认 → 视频作为一张身份参考图使用。** 这是在已有整板任务内调整布局的候选建议，没有增加生成次数或布局编辑器，本轮尚未改为实施要求。

面部区域可约占左侧1/3，右侧放三个全身视图；比例是起点，不硬套所有画布。有限分辨率下四个区域也可能挤小人物，必须按模型可用尺寸、下游比例上限和实际可读性判断。人物全身等高、脚底齐平，面部特写只放大同一个人的脸，不能变成另一个人物。

主图应先确认再生成整板，避免直接文生图一次造出多个看似相同但未确认的身份。帖子展示文生图直出不意味着本项目必须取消确认流程。主图本来脸部模糊时，整板模型可能重设计五官；提示词无法恢复原图没有的身份细节。

## 不直接照搬的词与布局

- 虚幻引擎、PBR是三维外观提示，不适用于所有写实、二维、水墨项目，也不表示真实调用了渲染器。
- “无阴影”与“细腻立体光影”不宜同时强制：建议背景干净、投影克制，人物面部和衣褶保留符合画风的层次。
- “8K”是正文里的描述，不能替代API尺寸配置，更不能为此自动升分辨率和成本。
- 特写＋三视图采用同一人物、同套服装，不混用另一角色的肤色、配饰、发型示例。
- 多表情、服装局部、比例尺与文字标签先不加入给视频使用的板；当前目标是可读的身份与服装参考，而非完整美术档案。

### 评论带来的新判断

1. **主图质感与参考板用途需要区分。** 半写实示例清楚限定CG/BJD并降低真人毛孔，说明“更有质感”不等于统一加真人皮肤和写实摄影。应按用户选定画风描述可见材质、五官结构与光影；完整身份图仍需用户确认。
2. **同板支持节省参考图名额，但不保证身份正确。** 既有大脸＋完整全身三视图案例，也有无头布局的失败反馈。建议继续以完整正侧背＋一个清晰脸部区域为候选，不增加多表情和多套衣服；四区像素是否足够仍要实图验收。
3. **不要把不同帖子拼成万能长提示词。** 浅景深与所有视角清晰、纯平光与戏剧性强轮廓光、真实毛孔与人偶哑光可能冲突。角色板优先身份、比例、服装结构和全图可读性；叙事气氛交给镜头。
4. **评论中的自动提取内容需要回看原图。** 小白AI帖里两条“点点”回复都称提取第五张，服装却分别写西装马甲与西装外套等不同内容。本轮没有打开第五张判定哪条准确，因此不将任一AI回复作为原提示词引用。
5. **没有充分证据要求换模型或增加生成次数。** 作者和读者口中的image2、image2.5、豆包是自述，未提供完整供应商、模型ID、输入图、尺寸与质量参数。先修复项目已确定的整板来源/确认/防重缺口，再由用户做小额真实验收；不要为追逐精选成图自动反复请求。
