# 界面与生成质量优化方案

日期：2026-10-08。目标是项目能跑通，界面更整洁，生成内容质量更好。不做上线类准备（鉴权、计费、合规、备份、HTTPS）。

基线：前端 e2e 82/82 通过，后端 pytest 949 通过、3 跳过，tsc、ruff、mypy 均无报错。

## 执行顺序

1. 第一批（本轮）：B1 清理浅色残留、B2 技术信息折叠、B6 剧本编辑器重做。
2. 第二批：A1–A5，只改提示词和规则，不增加模型调用。
3. 第三批：A6–A9，B3–B5。

每批独立验收，通过后再开始下一批。

## B 界面

### B1 清理浅色残留（第一批）
- `styles.css` 前约 120 行是旧的浅色主题，后面再用暗色覆盖，没覆盖到的地方漏出了白底：
  - 选中的场景卡片
  - 错误条（浅粉）
  - 剧本拆分页（`.script-split-panel`、`.story-source-paper`）
  - 未加样式的按钮和字段
- 做法：在文件末尾加暗色修正层，不删除旧规则，避免影响其他模块。
- 验收：e2e 全部通过；剧本、分镜、角色、画面、声音、导出各页面截图里没有浅色块。

### B2 技术信息折叠（第一批）
- 新增 `TechDetails` 折叠组件。以下内容默认收起，展开后才可见：
  - 作业编号、供应商任务号、配置版本、hash
  - 计费免责长句
- 不加开发者模式开关，用户需要时点开即可。
- 涉及文件：
  - `VideoJobPanel`
  - `VisualPreparation`
  - `CharacterReferences`
  - `CharacterWorkspace`
  - `ExportWorkspace`
  - `AudioWorkspace`
  - `VisualWorkspace`
- 约束：e2e 断言依赖的文字只能移进折叠区，不能删除。

### B6 剧本编辑器重做（第一批）
现状问题：
- 所有字段平铺成一张长表单。
- 标签只有 9px，字号 10px，读起来费力。
- 镜头之间没有视觉分隔，看不到时长和字数是否超标。
- "准备场景参考图"按钮没有样式。
- 左侧只列场景，看不到镜头。

改法：
- 左栏：场景列表，每个场景下展开它的镜头（序号、标题、时长），点击后跳转到对应镜头。
- 顶部：剧本标题 + 统计条，显示场景数、镜头数、总时长和目标时长、台词超标镜头数。
- 场景头卡片：场景标题，时间和地点放一行，叙事目标、冲突、转折放一行，场景参考图按钮做成次要按钮。
- 镜头卡片：
  - 头部：序号、标题、景别、时长输入、台词状态徽标。台词按 4 字/秒估算，并给动作和反应留 1 秒。
  - 主体两列。左列"画面"：画面描述、动作、情绪、运镜。右列"声音"：对白、旁白，并实时显示字数和建议上限。
  - 折叠区：动作三阶段（保留现有）；"视觉风格 / 环境声 / 配乐"。
- 字号：标签 12px，输入 13–14px，行高 1.6。
- 保持不变：
  - 所有 `aria-label`（e2e 依赖）
  - 按钮文案："保存剧本"、"确认剧本并生成分镜"、"重新拆分剧本"、"准备场景参考图（图片 API，可能计费）"
  - 保存、确认逻辑与数据结构
- 不新增后端接口，不调用模型。

### B3–B5（第三批）
- B3：步骤导航，显示完成状态；"资源"换图标并移到右侧。
- B4：镜头缩略图使用已采用素材的真实画面。
- B5：统一设计令牌，包括颜色、字号（≥12px）、圆角和三类按钮。

## A 生成质量
