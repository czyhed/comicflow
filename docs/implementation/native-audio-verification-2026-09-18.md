# 12A 原声、字幕与导出交互验证

日期：2026-09-18。状态：本地实现与离线验收完成；未提交、推送、部署或启动业务服务。

## 决策与范围

用户同意先评估声音功能，再授权本地实施并保留回溯。MiniMax H3 已有视频作为原声来源，不再强制生成独立配音或提取 WAV。其他模型的独立配音保留显式入口；浏览、页面跳转、预览、合成不能隐式调用生成模型。

本次只完成任务12A：公共导航、声音与字幕页、导出页及其必需的合成门禁。任务12全站清理、11历史资源、02准备单、03持久视频作业等没有因此全部完成。没有变更 H3 生成参数、Skill 路由、供应商配置、服务器连接或数据库结构。

## 已实现

| 入口 | 改动及失败行为 |
| --- | --- |
| 声音与字幕 | 没有 timeline 也能使用当前有效 H3 视频地址试听；媒体失败可刷新地址。切镜头更新只读对白/旁白，进入剧本时保留所在场景。修改剧本不会改变旧视频音轨。 |
| 合成门禁 | 当前有效 H3 视频可作为音频来源，不要求 audioAsset。FFmpeg 检查实际媒体；有台词却无音轨时以 COMPOSITION_AUDIO_MISSING 失败，保留视频，不调用 TTS/口型兜底。 |
| 声音优先级 | H3 始终使用当前视频原声，不被旧 TTS 或旧提取 WAV 覆盖。原有显式原声提取接口仍保留；非 H3 的独立配音要求保留。 |
| 自动/批量流程 | 自动阶段遇到 H3 跳过独立音频准备；批量 both 在新视频为 H3 时同样跳过配音。 |
| 字幕 | 显示为剧本草稿，不声称已经识别或对齐声音；同镜头同时有对白和旁白时两者均写入 SRT。仍是一镜头一条时间段，未实现 ASR/强制对齐。 |
| 导出 | 缺素材只导航到对应页面；合成只提交 composition，pending/queued/running 禁止重复点击。已有成片可读取签名链接预览视频/封面、查看字幕，失败可见。下载提示是“已发起”，不虚称浏览器已保存。 |
| 公共导航 | 移除空筛选、收藏、网格/列表、假身份等占位；显示加载/读取失败；会话操作 pending 禁用并展示失败。历史资源入口待11实现。 |
