# 镜头接续与裁剪

日期：2026-10-09。用户授权先备份后实施，目标是让用户用已有素材去掉镜头首尾多余停顿，并可在下一次主动生成时选择严格尾帧接续。

## 范围与契约

- composition 增加可选 shotTrims：镜头 ID 到 {inSec, outSec} 的映射。范围须有限、非负、出点大于入点，镜头须在合成范围内且采用视频。参数保存在作业，不修改剧本、源视频或采用状态。实际出点不得超过文件时长，FFmpeg 检查并明确失败，不补帧。
- 图像与原声使用相同裁剪区间，输出时间从零开始。字幕仍是镜头级剧本草稿，按裁剪后的时长累计，不能保证被裁掉的台词自动删掉或逐句对齐。选中镜头试片沿用独立文件和作业，不覆盖完整导出。
- 视频准备单和作业请求增加可选 continuityMode=previous-tail。只允许 H3 同场景后续镜头，要求已采用上一镜头尾帧；与显式关键帧冲突时阻断。严格 i2va 不混入角色参考图片，角色文字信息保留。默认 auto 保留原参考策略。选项必须贯穿准备、提交、完成新鲜度检查和采用。
- 新生成视频帧按源视频对象键隔离，防止不同项目同名镜头或历史候选覆盖尾帧。旧媒体和旧帧不改写。
- 不自动识别静止、不自动改变剧本、不加全局淡化、不自动重新生成或调用真实模型、不推送或部署。

## 实施结果与使用

已完成以上接口与本地页面。导出 → 选中镜头 → 镜头裁剪：选择镜头，查看原视频，输入入点/出点或用当前播放位置设置；“预览裁剪”播放该区间，“合成选中镜头”保存新试片。默认不裁剪；未调整的镜头仍采用原计划时长。可同时选择全部就绪镜头，输出完整长度的独立试片。裁剪草稿为当前页面状态，切离页面后须重新设置，已提交参数和产物保存在作业中。不会自动猜测停顿长度。

画面 → 生成准备单 → 镜头接续：选择“连续动作 · 上一镜头尾帧作首帧”，检查严格首帧清单后由用户显式生成并采用候选；批量生成仍沿用默认参考策略。第一镜头、不同场景、非H3或显式关键帧冲突时明确阻断。此选项只约束新生成输入，不改变已有视频。

真实FFmpeg测试通过红/蓝两段画面和220/880Hz音频构造已知切点，验证裁剪后保留蓝色画面和880Hz声音，下一镜头字幕从0.6秒开始，总时长1.6秒，源视频字节不变。越界出点明确失败、无模型补偿。准备单→提交→执行→采用的严格模式测试通过；默认ref2va契约保留。同名镜头的不同源视频帧键隔离测试通过。
