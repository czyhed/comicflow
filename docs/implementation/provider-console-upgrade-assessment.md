# API 管理扩展评估与实施结果

日期：2026-09-09。结论：可在现有管理页按能力逐步完善，已接入文本、独立参考图片、优云 H3 视频配置和强制 Skill 扩写。用户随后指定优先实施的角色提示词助手也已接入：文本 API 生成中文草稿，编辑采用后保存，再供图片 API 使用。全自动生产还需要配置共享与现有回归修复。未调用收费模型。

## 能力与范围

| 能力 | 当前实现 | 边界与下一步 |
| --- | --- | --- |
| 中文故事、剧本 | 现有文本 API，支持兼容 chat/completions 的地址、模型、密钥 | 候选服务需支持当前 JSON 输出契约，填写地址不等于验证兼容 |
| 角色身份与提示词 | 剧本提交建卡/绑定；角色页文本 API 生成外观、服装、性格和参考图提示词草稿 | 显式预览、采用、保存后使用；不直接覆盖手填值，不自动生成图片 |
| 角色参考图、场景背景 | 独立百炼万相 Adapter；可配置端点、模型、密钥、尺寸、超时 | 同协议可更换服务；OpenAI Images 等其他协议需要新 Adapter。当前为全身正面角色图和无人物场景图，未实现三视图 |
| H3 视频 | 优云 CompShare，独立密钥、模型、提交/查询路径、超时 | 本地契约已验证，真实模型质量和账户可用性未验证 |
| H3 Skill 扩写 | 每个 H3 请求都加载 Skill + base 指南；ref2va 再加载 ref 指南，使用当前文本 API | 没有独立 Skill 密钥。更换文本模型后会重新绑定；禁用文本模型后 H3 拒绝生成 |
| TTS、口型、合成 | 管理页只读展示实际运行时 Adapter | 保留环境配置，未新增可编辑管理。先核验协议、声音清单、异步状态及合成消费契约 |
| 配置持久化与 Worker | 沿用进程内配置，读取只返回掩码 | API 重启恢复环境变量；Worker 不读取页面更新。尚不能视为共享配置中心 |

这次是在已有 Provider seam 上完善功能。Skill 是视频提示词规则：先由图片 API 生成参考资产，再由文本 API 按 Skill 编译视频 Prompt，最后交给 H3。图片 API 不会执行 Skill 文档，也不能保证通过任意模型名称切换到另一种 API 协议。

## 已接入的数据流和接口

1. 中文剧本保存后建立角色身份；用户补全角色外观、服装并保存。
2. 在角色页或剧本场景栏显式准备参考图。启用独立图片能力后，确认剧本也会准备缺失参考资产，因此可能计费。
3. 图片 Adapter 解码供应商文件并转存 PNG；流水线检查图片类型及 URL，拒绝 MP4。已确认图片类型的资产复用；角色外观/服装改变使旧参考图失效。
4. 每次生成 H3 镜头，重新加载 `skills/h3-prompt-writing/SKILL.md` 和实际模式指南。按真实参考资产生成 Picture 标签、时长和模式清单。
5. 当前文本模型返回三节或六节结构，检查对白保留、描述语言、标签、模式与时长。成功才提交 H3；英文 Prompt 保存到视频资产，不回写中文剧本。
6. 视频资产记录 Prompt、Skill 文件列表及内容摘要，下载视频时不向外部资产域名发送优云密钥。

支持模式：t2va、i2va、fl2va、l2va、图片参考 ref2va。4–15 秒整数时长，最多 9 张图片。关键帧与多参考模式互斥，冲突直接拒绝，不丢弃引用。t2va 镜头带有效角色/场景参考图时推导为 ref2va；此模式不同时套用尾帧级联。参考视频/参考音频未接入。

文本扩写接收参考 URL 和角色/场景元数据，未做视觉读图。结构校验不等于艺术质量或跨镜头一致性保证；相关质量仍需后续小样本人工验收。

| 接口 | 用途 |
| --- | --- |
| `GET /api/provider-config` | 文本、图片、视频掩码配置、Skill 绑定与运行时状态，声明 `scope=api-process` |
| `PUT/DELETE /api/provider-config/media/{image\|video}` | 保存或清除本进程媒体配置；保存先校验再切 Adapter，不访问供应商 |
| `PUT/DELETE /api/provider-config/text` | 更换文本配置，同时更新 H3 Skill 执行器 |
| `POST /api/projects/{id}/references/{characters\|scenes}/{targetId}` | 使用 `expectedVersion` 准备或复用参考图；检查项目访问与目标归属 |

配置清除不会删除环境变量，重启后环境配置可重新生效。控制台目前用于本地单用户开发；管理员鉴权、权限隔离及配置审计尚未完成。

## 配置方式与消耗

进入“模型 API 配置”：

- 文本：保存可用的文本 API 地址、模型和密钥。它同时承担中文剧本与 H3 Skill 扩写。
- 图片：选择百炼万相协议，默认地址 `https://dashscope.aliyuncs.com/api/v1`，模型 `wanx2.1-t2i-plus`；填写该协议对应密钥，启用后才会准备参考图。
- 视频：选择优云 H3，默认地址 `https://cp.compshare.cn`，模型 `MiniMax-H3`，提交路径 `/minimax/v2/video_generation`，查询路径 `/minimax/v2/query/video_generation/{task_id}`。
- 保存配置本身不收费。现有文本连接测试、角色/场景生成按钮和确认剧本后的资产准备都可能收费，本轮未点击真实生成按钮。

需要 API 重启后及新启动 Worker 使用同一基础配置时，参照 `.env.example` 的 `TEXT_PROVIDER_*`、`IMAGE_PROVIDER_*`、`MINIMAX_*` 和对应启用开关配置环境；页面保存不会写入 `.env`。本轮未修改实际 `.env`，也未重启 Worker。

每个成功提交的视频请求前增加一次文本扩写调用；扩写失败不自动重试，也不提交视频。重新生成视频会重新执行 Skill。已保存且类型有效的参考图复用，不重复生成。没有价格或余额核验，不承诺具体消耗数值；自动作业层重试和供应商幂等仍需统一审计。

## 分阶段后续任务与验收

### P0：修复现有离线生产阻塞

- 输入：当前 11 项失败，见 `.scratch/2026-09-09-script-language-repair/skill-api-regression.txt`。
- 输出：按真实尾帧能力判断级联；统一旧 `split_script/_generate_script` 的 Script/envelope 契约，并复用项目角色绑定逻辑。
- 失败行为：真实视频缺尾帧时保持明确拒绝，不用静态占位图假装成功。
- 门禁：现有失败转绿、新 Skill/图片/配置回归保持通过；仍不调用真实模型。

### P1：让 API 管理成为可恢复的共享配置

- 输入：进程内能力配置，既有 Provider Console 第二阶段设计。
- 输出：PostgreSQL 加密保存、外部加密密钥、管理员权限、审计、配置版本、API/Worker 共享读取。作业引用配置版本，队列不携带 API Key。
- 失败行为：解密失败、版本失效、配置缺失显式报错，禁止静默切到另一个收费模型。
- 门禁：API/Worker 重启保持同一配置；运行中修改对新作业生效，旧作业处理策略可验证；密钥不进入响应、日志、队列和浏览器存储。

### P2：角色设定助手与参考资产生命周期

- 2026-09-09 补充：用户指定的角色设定/提示词草稿流程已完成，见任务书末节与 HANDOFF 顶部；以下资产生命周期和事务条目仍是后续任务。
- 输入：剧本中已确认角色、用户已有设定及选择的文本 API。
- 输出：“生成角色设定草稿 → 中文预览 → 用户保存 → 图片 API”流程；不覆盖手填值，不自动收费生成画像。
- 补齐：改名同步引用、角色与剧本写入事务；场景修改/剧本重存的参考图保留和失效策略；模型/尺寸变化后的显式重建；跨进程幂等和重复确认保护。
- 门禁：生成失败不改变旧角色；预览不写库；确认重放不重复扣费；编辑与生成并发不会覆盖新版本。

### P3：其他协议和真实验收

- 图片换供应商时补 Adapter、离线请求/轮询/下载契约测试，再加入管理页选项。
- TTS 与口型先核验协议及资产消费，再加入可编辑配置。不要把现有原型等同于可用能力。
- P0/P1 与相关离线门禁通过后，经用户允许安排一个最短镜头的真实验证，再评估双角色/跨镜头一致性。旧 MP4 背景需显式生成有效图片，不批量覆盖历史资产。
