## 已实现

- 新增 `providers/xiangongyun_h3.py` 与 `xiangongyun-h3` 协议。主模型库动态显示「仙宫云 MiniMax H3」，旧配置页也提供入口；复用原连接、加密保存、用途绑定、配置版本和任务检查点。
- 提交 `POST /api/v1/jobs` 为 multipart，要求 202 与有效 `prompt_id`；无图片的文生视频也使用 multipart。查询 `GET /api/v1/jobs/{prompt_id}`，兼容文档的 `data` 包装与未包装对象。
- 支持现有 `t2va/i2va/l2va/fl2va/ref2va` 图片模式。参考图从现有 MinIO objectKey 或合法 data URL 读取为文件；首尾帧与普通参考图互斥，最多9张、4–15整数秒。
- 普通参考图通过重复的 `reference_images` 字段及 `reference_manifest` 绑定。按素材顺序构建 index/external_id，以稳定哈希前缀的 `@mention` 对应现有 `<Picture N>` 标签；首尾帧单独上传。准备单展示与实际提交相同的中文提示词、引用标签和参数。
- 默认 `context-ir` 复用 ComicFlow 本地中文编译 v3，不调用文本扩写；显式发送 `compile_prompt=false`，避免远端再次改写对白。选择 `local-skill` 时仍会使用当前视频提示词文本模型，但本批仅离线测试。保留现有编译器7000字符预算，转换后另守仙宫云10000字符上限。
- 下载仅接受同源 `/api/v1/output`，携带 Bearer，拒绝跳转、空响应和非视频/二进制响应类型。成功后沿用现有 MinIO 保存与候选采用流程。未使用远端持久资产库，因此无需创建或删除远端素材。
- 提交前检查点恢复会重新从本地素材库读取图片，并复用已编译文本；已有 taskId 时只查询/下载。提交结果不明保留 unknown，不能自动重新生成。畸形完成响应保留可恢复错误，明确失败终态才视为生成失败。
- 实际分辨率与推理档位进入作业配置签名，避免中断后换档提交。原 CompShare 代码及旧适配器的配置签名保持原状。

## 复用现有连接

以下步骤用于 API 和 Worker 都已加载本批代码之后；本批未代替用户修改运行中的模型库。

1. 顶部「模型 API」→「模型列表」→新增模型，选择已保存的仙宫云连接。无需新建重复连接或重填未改变的密钥。
2. 调用协议选「仙宫云 MiniMax H3」，模型 ID 填 `MiniMax-H3`，启用后保存。该 ID 用于 ComicFlow 记录；仙宫云此端点不接收 `model` 字段。
3. 「用途选择」中把「镜头视频」绑定到该模型。保存/绑定不提交生成，历史模型保留。

连接基础地址使用带 `http://` 或 `https://` 的实例 `web_url` 根地址，不加 `/v1`、`/api`、`/api/v1/jobs` 或查询参数。API Key 填实例 `jupyter_token`，不是仙宫云平台管理 API Key。实例重建后地址和令牌可能变化，以实际控制台为准；不要将令牌贴入文档或日志。

默认参数已由协议模板填入：

```json
{
  "timeoutMs": 600000,
  "resolution": "0.5P",
  "inferenceProfile": "turbo8_av_sol_gpu_te",
  "h3PromptMode": "context-ir"
}
```

`0.5P` 对应横屏960×544、默认竖屏544×960，优先减少初次验证的像素负担；它不是 CompShare 的768P等价档，也不代表已测成本或质量。可在模型参数中改为文档规定的 `0.4P`—`1.0P`。画幅沿用镜头的9:16或16:9；其他比例拒绝。推理档位可选极速 `turbo4_av_sol_gpu_te`、默认平衡 `turbo8_av_sol_gpu_te`、质量 `quality_av_sol_gpu_te`。

默认无需再配置提交/查询路径、宽高或远端资产 ID。只有外部图片 URL、没有本地 objectKey/data URL 的旧引用会在文本扩写和视频提交前拒绝；需要先保存图片到现有素材库。本批未扩展视频/音频参考上传，也未代管实例。
