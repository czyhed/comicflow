## 风格库体验与规则

创建时选“真人电影写实、国风三维动画、日系二维动画、国风厚涂、水墨动画、美式漫画”；可保留未统一设置兼容旧流程。14A在新建前选择，保存后显示当前项目名称及版本，明确下一次选择只影响新项目。角色/场景/视频各自使用同一预设的阶段规则，角色板强调身份辨识，场景强调空间动线，视频强调时间连续与画风稳定。

题材/时代/情绪与画风分离；风格不绑定某家供应商，不暗中切换image-2.5、H3或分辨率。预览图后续用有来源的示意素材，不承诺模型效果，不自动消耗额度生成图库。旧项目换风格、自定义/收藏属于14B/C，第一批无占位可点击按钮。

## UI责任划分

创建页：故事输入、时长、风格和明确的下一步；模型选择/质量控件是否实际生效在12B核实后移除或接通，不能保留假控制。角色页：候选→确认→角色板，减少重复生成入口。画面页：左侧镜头列表、中间预览、右侧准备信息和任务状态；窄屏折叠为顺序区块。资源页：当前/历史可辨，来源清楚；导出继续只负责合成和交付。

12B随02接参数和修正假展示；04A随03接真实任务状态；12C再统一字号/间距/按钮/空状态/弹窗焦点与卡片。没有对应API的功能不画成可用按钮。不为美化增加新的全站状态库或UI框架。

## 准备单契约

展示实际模型/配置版本、分辨率/画幅/时长、风格快照、人物/场景/尾帧的图片与用途、动作起中终及准确对白、提示词模式、缺项与预计调用次数。只读编译不调用模型；local-skill显示扩写输入而非伪造最终提示词，平台优化内部结果标不可见。费用无依据时显示未知，既有宽泛Credits估计不能冒充供应商报价。

预览与提交共用编译；版本/素材/模型发生变化须重新准备。包含普通生成、批量、会话/Worker入口，不能只保护一个按钮。素材错误能离线发现，画质/动作执行仍需用户验收。
