## 1. 产品目标、范围与成功指标

### 1.1 产品目标

让用户从中文故事或一句话创意出发，经过可编辑的剧本、分镜、角色卡和资产生成流程，得到一份可下载的竖屏漫剧。产品必须将生成过程变成可管理的生产流水线，而不是一次性黑盒生成。

### 1.2 MVP 范围

**P0 必须交付**：创建向导、故事审核、剧本生成、剧本/分镜编辑、角色卡、动态镜头生成、基础角色动作与表情、基础中文口型同步、镜头运动、中文配音、字幕、商用音乐和音效、异步进度、失败重试、局部重新生成、额度预估与结算、匿名体验、登录认领、FFmpeg 合成、视频预览、MP4/封面/SRT 导出、Mock 全链路。

**P1 可交付**：SSE 实时进度、项目级角色覆盖、资产历史版本、复杂动作与高级口型能力、基础运营指标。

**MVP 明确不做**：抖音直发、声音克隆、上传角色参考图、无限多人群像、专业级时间线编辑、角色交易、多人协作、多画幅、自定义编码、原生客户端。

### 1.3 成功指标

| 指标 | MVP 目标 | 统计口径 |
| --- | --- | --- |
| Mock 端到端完成率 | ≥95% | 从故事提交到导出包成功 |
| Mock 导出成功率 | ≥98% | 合成作业成功且三件导出物齐全 |
| 单镜头返工范围 | 不需要整项目重做 | 局部重新生成记录 |
| 真实 60 秒项目外部成本 | 目标 ≤10 元 | 额度账本 + 供应商账单 |
| 阻断错误可理解率 | 100% 有中文原因与下一步 | 错误码审计 |

## 2. 用户角色与权限

| 角色 | 可做操作 | 不可做操作 |
| --- | --- | --- |
| 匿名会话 | 创建临时项目、提交故事、预览生成结果、体验 Mock 流程 | 跨设备访问、永久保存、下载导出包、创建个人角色库 |
| Owner | 读取/编辑项目、生成资产、重试/取消、保存、导出、管理个人角色卡 | MVP 不支持邀请成员 |
| Editor（预留） | 数据模型预留，不开放 UI | 当前版本不可用 |
| Viewer（预留） | 数据模型预留，不开放 UI | 当前版本不可用 |

权限规则：所有项目、作业和资产读取都必须校验 Project Owner；签名 URL 只能访问当前用户有权访问的资产；登录认领匿名项目必须幂等，重复回调不能产生重复项目。

## 3. 全局导航与信息架构

### 3.1 主导航

桌面端左侧固定显示：项目名称、当前模式、阶段导航、帮助/AI 助手入口。主内容区显示当前阶段；顶部显示项目版本、额度余额、保存状态和用户身份。阶段顺序固定为：

`创建 → 剧本 → 分镜 → 角色 → 画面 → 声音 → 导出`

阶段状态使用颜色和文本双重表达，不能只依赖颜色：未开始、进行中、待确认、已完成、失败、已取消、已失效。

### 3.2 全局操作

- 保存：保存当前编辑，成功后显示“已保存时间”；冲突时禁止静默覆盖。
- 撤销：仅撤销当前表单未提交的编辑，不跨版本回滚。
- AI 助手：只能读取当前项目快照并提出修改建议；用户确认后才调用生产流水线。
- 额度：点击显示当前余额、已预留、预计消耗和最近账本记录。
- 阶段跳转：只能进入已完成、当前或允许查看的上游阶段；下游未生成时显示空状态。

## 4. 页面需求详述

### 4.1 创建向导

**页面目标**：让匿名用户在 2 分钟内提交一份有效故事，并明确知道生成模式、预计产物、预计 Credit 和匿名限制。

| 字段/控件 | 类型 | 必填 | 规则 | 默认值 |
| --- | --- | --- | --- | --- |
| 输入类型 | Tab | 是 | `故事`或`一句话创意` | 故事 |
| 故事内容 | 多行文本 | 是 | 故事 50～10,000 字；创意 10～200 字；禁止纯空白 | 示例故事 |
| 目标时长 | Select | 是 | 30～90 秒，步长 5 秒；默认 60 秒 | 60 秒 |
| 生成模式 | Radio | 是 | 逐步确认 / 全自动 | 逐步确认 |
| 预计镜头 | 只读 | - | 根据时长显示建议 6～12 个 | 6 个 |
| 预计消耗 | 只读 | - | 按当前 Provider 配置计算 Credit 区间 | 24 Credit |
| 提交按钮 | Button | - | 审核通过、额度足够、字段有效时可用 | 可用 |

**交互与状态**：提交后按钮变为“审核中”并锁定表单；审核通过进入剧本阶段；审核阻止停留当前页并显示原因码、中文原因和修改入口；额度不足显示所需/可用额度并禁止提交；网络失败保留表单且重试幂等。

**验收**：两类输入均能提交；长度边界定位到输入框；提交前能看到时长、镜头数和 Credit；刷新后匿名项目和作业可恢复。

### 4.2 剧本阶段

**布局**：左栏为项目摘要和作业，中栏为剧本摘要与场景列表，右栏为当前场景编辑和 AI 建议；顶部固定显示待确认、保存和确认按钮。

| 对象 | 字段 | 类型/限制 |
| --- | --- | --- |
| Script | 标题 | 1～80 字 |
| Script | 故事摘要 | 20～500 字 |
| Scene | 场景标题 | 1～80 字 |
| Scene | 时间/地点 | 各 1～100 字 |
| Scene | 叙事目标 | 1～300 字 |
| Scene | 旁白 | 0～1,000 字 |
| Scene | 场景顺序 | 正整数，可拖拽排序 |

支持场景新增、复制、删除和排序；删除前提示影响镜头数；AI 改写必须展示差异，用户确认后才保存新版本；确认前校验至少一个场景、必填字段、审核结果和版本号。修改剧本使所有关联下游结果标记 `stale`，但保留历史资产。

### 4.3 分镜阶段

| 字段 | 类型/限制 | 默认/校验 |
| --- | --- | --- |
| 镜头编号 | 只读 | 按排序自动编号 01～12 |
| 镜头标题 | 文本 1～80 字 | 必填 |
| 画面描述 | 文本 1～500 字 | 必填 |
| 动作 | 文本 0～300 字 | 与画面描述至少一项非空 |
| 对白/旁白 | 文本 0～1,000 字 | 可无对白 |
| 情绪 | Select | 平静、紧张、悲伤、惊讶、愤怒、喜悦等 |
| 景别 | Select | 特写、近景、中景、全景、远景 |
| 时长 | 数值 | 3～20 秒，步长 1 秒 |
| 主要角色 | 多选 | 0～2 个角色 |
| 运动模式 | Select | 静态、推近、拉远、平移、关键动画 |
| 转场 | Select | 直切、淡入淡出、叠化 |

支持新增、复制、删除、拖拽排序。页面实时显示镜头数和累计时长，确认必须满足 6～12 个镜头、30～90 秒。第三个主要角色立即阻止保存并显示“双角色上限”。全自动模式可暂停转为逐步确认。单镜头修改只使本镜头及其下游失效，场景修改使场景内镜头失效。

### 4.4 角色阶段

提供“系统角色模板”和“我的角色卡”两个 Tab。系统模板可预览和复制；个人角色卡可新建、编辑、归档和跨项目引用。角色卡字段：名称 1～40 字且个人库唯一；外观 20～500 字；服装 5～200 字；性格 5～200 字；声音选择为系统音色 ID；来源 system/user；版本只读递增。

从模板复制创建用户角色，不修改系统模板。修改被项目引用的角色时提示影响范围并允许创建项目覆盖。删除有引用的角色只能归档。角色卡修改使引用该版本的画面和配音失效。

### 4.5 画面阶段

左侧为镜头列表，中间为竖屏动态预览画布，右侧为生成参数和资产版本。默认生成 9:16 动态漫剧镜头；输入由镜头描述、角色卡设定、动作、表情、景别、情绪和风格组成，UI 不拼接 Provider Prompt。镜头运动包含推近、拉远、平移和转场；动态模型不可用时才回退到局部 2D 动画或静态运动，并显示回退状态。

镜头重生成弹层必须显示预计 Credit、会失效的下游资产和保留资产；确认后只创建目标镜头作业；失败保留旧版本，成功替换当前有效画面版本。

### 4.6 声音与字幕阶段

| 资产 | 方式 | 约束 |
| --- | --- | --- |
| 中文配音 | 角色音色生成 | 以实际音频时长为准 |
| 字幕 | 对白 + 配音时间轴生成 | UTF-8 SRT，底部安全区 |
| 背景音乐 | 商用授权内置素材 | 对白区间自动压低 |
| 音效 | 商用授权内置素材或 Mock | 可按镜头替换 |

时间轴统一保存动态画面、角色动作、表情、口型、镜头运动、转场、对白、字幕和音轨。TTS 音频是对白时序事实来源；字幕和口型时间轴必须由实际音频时长生成。字幕片段必须有镜头编号、对白段落 ID、说话人 ID、开始时间、结束时间和文本，结束时间大于开始时间。配音时长变化后只使对应口型、字幕和导出失效，不默认重生成背景动作；超出 90 秒阻止合成。支持单镜头、连续播放、暂停、拖动播放头和人工修正口型。

### 4.7 作业、进度、审核与错误

作业状态：`queued`、`running`、`succeeded`、`failed`、`cancelled`、`awaiting-confirmation`、`stale`。阶段进度显示当前阶段、已完成镜头/总镜头、百分比和可计算的剩余时间；镜头进度显示对象状态。SSE 断线按最后事件编号恢复，不可用时每 3 秒轮询。

| 错误类 | UI 行为 | 重试 |
| --- | --- | --- |
| 输入无效 | 定位字段并给修改建议 | 修改后提交 |
| 审核阻止 | 显示原因码和合规提示 | 修改后重试 |
| 额度不足 | 显示所需/可用额度 | 补充或降低范围 |
| Provider 限流/超时 | 显示系统重试中 | 有限重试 |
| Provider 不可用 | 显示暂不可用 | 用户重试 |
| 版本冲突 | 提示刷新或复制修改 | 解决后保存 |
| 合成失败 | 显示对象和追踪 ID | 可重试 |

### 4.8 登录、匿名认领与额度

登录使用邮箱验证码或魔法链接。登录入口出现在保存、导出、跨设备访问和创建个人角色时。登录成功后事务化、幂等地将匿名项目认领给 User；失败不丢失当前故事。

Credit 规则：生成前展示明细；启动前写 `reservation`；成功写 `settlement` 按实际用量结算；失败/取消写 `release` 释放未使用部分；账本只追加。真实 60 秒项目预计外部成本超过 10 元时提示并可阻止启动，Mock 不产生外部成本。

### 4.9 导出阶段

导出要求用户已登录且为 Owner，所有必需资产为当前有效版本，无审核阻断，镜头 6～12 个且总时长 30～90 秒；重复点击使用同一幂等键。

| 输出 | 规格 |
| --- | --- |
| MP4 | H.264/AAC、1080×1920、9:16、30 fps |
| 封面 | 首个有效画面抽帧或固定封面，PNG/JPEG |
| 字幕 | UTF-8 SRT，与当前时间轴版本一致 |

视频、封面、SRT 全部成功后才将 ExportPackage 标记为 `ready`。任一失败时不可下载，重试合成但不重生成上游资产。下载使用短时签名 URL；匿名点击导出先登录，登录后返回导出页。

## 5. 状态机与失效传播

阶段顺序：`story → script → storyboard → characters → visuals → audio → composition → export`。逐步确认模式在 script、storyboard、visuals、audio 完成后进入 `awaiting-confirmation`；全自动模式在审核、字段和额度校验通过后推进。

| 变更对象 | 失效范围 |
| --- | --- |
| Story | 当前剧本及全部下游 |
| Script 场景 | 该场景镜头及其下游 |
| 单个 Shot | 该镜头画面、音频、时间轴片段和导出 |
| CharacterCard 版本 | 引用版本的画面和配音 |
| 单类 Asset | 依赖它的时间轴和导出 |

Worker 写入结果前必须验证输入版本；旧作业不能覆盖新编辑。取消是协作式操作，已发生费用和资产照实记录。

### 5.1 动态镜头生成顺序

1. 锁定角色卡、场景、对白、动作、表情和镜头运动，生成 `ShotSpec`。
2. 对有对白的镜头先生成 TTS，保存音频、真实时长和词/音素时间信息。
3. 根据音频时间生成字幕和口型时间轴；仅对有对白且具备可见嘴部的角色调用口型 Adapter。
4. 生成动态画面候选，输入目标时长、动作区间和镜头运动；将口型/表情驱动应用到对应角色。
5. 生成低清预览，用户确认后再生成最终合成版本。

配音替换不应默认使动态背景失效；只使口型、字幕和导出失效。动作或镜头时长修改时，必须重新校验音频区间并标记受影响的口型和字幕片段。

## 6. 产品级接口契约

| 操作 | 输入 | 成功结果 | 失败结果 |
| --- | --- | --- | --- |
| 创建项目 | inputType、story、duration、mode | Project + GuestSession | 字段错误、审核阻止 |
| 获取生产快照 | projectId、version | 阶段、镜头、资产、额度快照 | 无权访问 |
| 提交阶段 | projectId、stage、version | GenerationJob | 冲突、额度不足、前置未完成 |
| 确认阶段 | projectId、stage、version | 下游作业排队 | 未通过校验 |
| 更新剧本/镜头 | patch、version | 新版本号 | 冲突、字段错误 |
| 局部重生成 | targetType、targetId、version | 新 GenerationJob | 无效目标、额度不足 |
| 重试/取消作业 | jobId、version | 新尝试或 cancelled | 不可操作状态 |
| 认领匿名项目 | guestSession、userId | Owner 归属完成 | 已认领/过期 |
| 请求导出 | projectId、timelineVersion | ExportPackage 作业 | 未登录、资产不完整 |
| 获取进度流 | projectId、lastEventId | SSE 事件 | 断线后轮询 |

所有错误包含稳定错误码、中文消息和追踪 ID；不返回供应商密钥、原始堆栈或完整敏感 Prompt。

### 6.1 动态镜头与口型接口

`ShotSpec` 至少包含 `shotId`、`durationMs`、`characterRefs`、`actionTrack`、`expressionTrack`、`cameraTrack`、`dialogueSegments`、`visualStyle` 和 `modelConfigVersion`。`DialogueSegment` 至少包含 `segmentId`、`speakerId`、`text`、`audioAssetId`、`startMs`、`endMs`、`subtitleId` 和 `lipSyncAssetId`。

生成接口必须支持四种范围：`visual`（只重做动态画面）、`audio`（只重做配音）、`lipsync`（只重做口型）、`shot`（重做整镜头）。每种范围返回新增作业、预计 Credit、失效清单和保留资产清单。

## 7. 数据、埋点与运营

核心实体：User、GuestSession、Project、ProjectMember、Story、Script、Scene、Shot、CharacterCard、GenerationJob、Asset、ModerationResult、CreditLedger、ExportPackage。必须保留版本号、时间戳、来源作业、幂等键、依赖关系、有效状态、媒体摘要、尺寸/时长、审核原因码和额度账本事件。

事件：`project_created`、`story_submitted`、`moderation_blocked`、`stage_confirmed`、`job_started`、`job_failed`、`job_retried`、`asset_regenerated`、`guest_claimed`、`export_started`、`export_ready`、`export_failed`。事件只携带脱敏 projectId、stage、targetType、mode、配置版本、耗时、Credit 和 traceId，不携带故事、Prompt、邮箱或音频文本。

## 8. 非功能、安全与运维

- 性能：普通读取接口目标 P95 < 500 ms（不含生成）；大文件直传对象存储。
- 可靠性：Web/Worker 重启可恢复；作业幂等；数据库每日备份并验证恢复；导出原子发布。
- 安全：HttpOnly/SameSite Cookie、项目级授权、短时签名 URL、密钥不入客户端/数据库/日志。
- 隐私：日志最小化；审核保存摘要和原因码；匿名项目有保留期；资产按用户隔离。
- 可观测性：追踪 ID、结构化日志、OpenTelemetry、错误聚合、成功率、阶段耗时、重试率、审核阻止率、单位成本、导出失败率。
- 兼容性：现代桌面浏览器；固定中文字体；MP4、封面和 SRT 可被常用播放器和剪辑软件读取。

## 9. 测试与验收

| 测试层级 | 覆盖内容 | 工具/方法 |
| --- | --- | --- |
| 领域测试 | 状态机、依赖失效、双角色、时长、额度账本 | pytest + pytest-asyncio |

| 集成测试 | PostgreSQL、Redis、对象存储、Worker 组合 | 容器化 + Mock |
| 端到端 | 匿名、确认、全自动、重生成、审核、额度、登录、导出 | Playwright |
| 媒体测试 | 编码、分辨率、帧率、时长、音轨、封面、字幕 | FFprobe/FFmpeg + 人工样例 |

必须通过：故事和一句话创意生成 6～12 镜头；逐步确认和全自动均可完成链路；双角色规则生效；资产可局部重生成；失败/取消/重试/审核/额度不足有操作反馈；Mock 可导出 MP4、封面、SRT；匿名和登录权限正确；项目经理可独立完成 UAT。

## 13. 状态、文案与跳转矩阵

### 13.1 阶段状态显示

| 状态 | 标签文案 | 可执行动作 | 是否允许进入下游 |
| --- | --- | --- | --- |
| 未开始 | 未开始 | 查看 | 否 |
| running | 生成中 | 查看进度、取消 | 否 |
| awaiting-confirmation | 待确认 | 编辑、确认 | 否 |
| completed | 已完成 | 编辑、重新生成 | 是 |
| failed | 生成失败 | 查看原因、重试、使用旧版本 | 否（除非旧版本有效） |
| stale | 已失效 | 查看变更、重新生成 | 否 |

### 13.2 关键跳转条件

| 当前动作 | 跳转目标 | 条件 |
| --- | --- | --- |
| 审核通过 | 剧本 | 自动跳转，或用户关闭“审核完成”提示后手动进入 |
| 确认剧本 | 分镜 | Script 校验通过 |
| 确认分镜 | 角色 | 镜头 6～12 个且时长合规 |
| 确认角色 | 画面 | 每个镜头引用的角色版本存在 |
| 确认画面 | 声音 | 必需镜头均有有效画面 |
| 确认声音 | 导出 | 音频、字幕、音乐和时间轴校验通过 |
| 点击导出 | 登录页 | 当前为匿名会话 |

### 13.3 空、加载、失败和成功状态

- 空状态：说明缺少的唯一前置条件，并提供一个主按钮，例如“先确认分镜”。
- 加载状态：显示当前对象名称、已完成数量和取消入口；不显示虚假的百分比。
- 失败状态：显示中文原因、错误码、追踪 ID、影响范围和主操作；技术堆栈仅写入日志。
- 成功状态：显示生成版本、耗时、Credit 实际消耗和下一步按钮。

## 14. 接口示例与保存契约

### 14.1 创建项目

```http
POST /api/projects
Idempotency-Key: 01J...
Content-Type: application/json

{"inputType":"idea","story":"雨夜里，修表匠发现停摆的表能倒流一分钟","durationSec":60,"mode":"guided"}
```

成功响应：

```json
{"projectId":"prj_123","version":1,"stage":"story","moderationJobId":"job_1","guestSession":{"id":"gst_1","expiresAt":"2026-09-07T00:00:00Z"},"estimate":{"shots":8,"creditMin":22,"creditMax":30}}
```

### 14.2 更新镜头（乐观并发）

```http
PATCH /api/projects/prj_123/shots/shot_03
If-Match: 7
Content-Type: application/json

{"durationSec":6,"emotion":"tense","motionMode":"push_in"}
```

成功返回新版本号和失效清单：

```json
{"version":8,"shotId":"shot_03","invalidated":["visual:shot_03:v2","audio:shot_03:v1","export:exp_2"]}
```

版本冲突统一返回 HTTP 409、`VERSION_CONFLICT`、服务器版本和用户版本摘要；客户端不得自动覆盖。

### 14.3 作业进度事件

```json
{"eventId":"evt_19","jobId":"job_9","stage":"visuals","targetId":"shot_03","status":"running","completed":3,"total":8,"percent":37,"traceId":"tr_abc"}
```

客户端按 `eventId` 去重，断线重连携带 `Last-Event-ID`；无法恢复事件时拉取 `/api/projects/{id}/jobs?since=`。

### 14.4 自动保存契约

草稿保存请求必须携带 `baseVersion`、字段补丁和客户端编辑时间。服务端返回 `version`、`savedAt` 和 `invalidated[]`。输入停止 800 ms 自动保存；连续失败 3 次后停止自动重试，改为显式“重试保存”，避免请求风暴。

## 15. 验收用例编号

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| AC-01 | 一句话创意创建 | 10～200 字可提交并生成 6～12 镜头 |
| AC-02 | 故事长度边界 | 49/10,001 字阻止，50/10,000 字通过 |
| AC-03 | 审核阻止 | 停留创建页，显示原因码、中文原因和修改入口 |
| AC-04 | 双角色上限 | 第三个主要角色无法保存且不改变已有数据 |
| AC-05 | 局部重生成 | 仅目标镜头及其下游变为 stale，其他镜头不变 |
| AC-06 | 版本冲突 | 返回 409，用户可刷新或复制修改，无静默覆盖 |
| AC-07 | Credit 结算 | 成功 settlement、失败 release、取消不重复扣费 |
| AC-08 | 匿名认领 | 登录后项目、作业、资产保持原 ID 且只能认领一次 |
| AC-09 | 导出规格 | MP4 为 1080×1920/H.264/AAC/30fps，SRT 与时间轴一致 |
| AC-10 | 合成失败恢复 | 可重试合成，不重新生成上游资产，旧导出不可下载 |
| AC-11 | 进度断线 | SSE 断线后按事件 ID 补齐，不重复显示进度 |
| AC-12 | 权限隔离 | 其他用户访问项目、作业、签名 URL 均返回 404/403 |
