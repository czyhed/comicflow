# 动态 AI 漫剧作为主链路

## 状态

已确认

## 背景

ComicFlow 的产品目标是生成动态中文竖屏漫剧，而不是静态图片幻灯片。此前的静态运动方案只能解决低成本和模型不可用时的连续交付问题，不能作为默认产品体验。

## 决策

- P0 的镜头产物必须支持角色动作、表情、基础口型同步或镜头运动中的至少两类动态表现。
- 分镜阶段记录动作、表情、说话角色和时间区间；声音阶段生成配音、口型时间轴和字幕时间轴；合成阶段统一对齐。
- 真实生产模型必须使用可部署在优云平台的免费模型或开放权重模型，避免持续调用付费 API。
- Mock 用于开发、演示和故障降级；静态图片加推拉平移仅作为动态模型不可用时的回退路径。
- 动态模型、口型模型和 TTS 均通过 Provider Adapter 接入，不能把供应商 SDK 直接散落在业务流程中。

## 影响

镜头、资产和时间轴数据需要保存动作、表情、口型和模型版本。局部重生成需要区分画面动作、口型和音频的失效范围。验收必须包含动态镜头、中文口型同步、模型故障回退和不重复扣费场景。
