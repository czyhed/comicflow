# 视觉风格参考指南

本文档提供常见视觉风格的描述模板，供用户在创作时参考。

## 使用说明

在剧本镜头的"视觉风格"字段中，可以输入以下任一风格描述，或者自由组合其中的元素。

## 风格分类

### 🎨 写实风格（Photorealistic Styles）

#### 1. 电影级写实
```
电影级写实风格，真实光影，丰富材质细节，自然色彩层次，空气透视明显
```

#### 2. 胶片质感
```
35mm 胶片质感，轻微颗粒感，温暖色调，自然饱和度，柔和对比
```

#### 3. 纪实摄影
```
纪实摄影风格，自然光源，真实环境，生活气息，克制后期
```

#### 4. 时尚大片
```
时尚摄影风格，精致布光，高对比，锐利细节，时尚色调
```


## 技术参数参考

### 光照类型
- Golden hour（黄金时刻）- 温暖怀旧
- Blue hour（蓝调时刻）- 冷静神秘
- Overcast（阴天）- 柔和忧郁
- Harsh noon light（正午硬光）- 对比强烈
- Candlelight（烛光）- 温暖亲密
- Neon lights（霓虹灯）- 现代都市
- Rim light（轮廓光）- 分离主体
- Silhouette（剪影）- 神秘戏剧

### 色彩方案
- 暖色调（温暖、怀旧、亲密）
- 冷色调（冷静、疏离、科技）
- 莫兰迪色系（优雅、文艺、克制）
- 高饱和度（活力、流行、年轻）
- 低饱和度（成熟、沉稳、文艺）
- 黑白灰（经典、情绪、艺术）

### 材质质感
- 胶片颗粒（复古、温暖、怀旧）
- 数字清晰（现代、锐利、直接）
- 油画笔触（艺术、厚重、表现）
- 水彩晕染（清新、梦幻、柔和）
- 平涂色块（现代、简洁、图形）

## 注意事项

1. **不要过度堆砌风格关键词**：选择 2-3 个核心元素即可
2. **保持风格一致性**：同一场景的多个镜头应保持相似风格
3. **风格要符合叙事**：悬疑场景用明暗对照，浪漫场景用柔光暖调
4. **测试和迭代**：生成后根据效果调整风格描述
