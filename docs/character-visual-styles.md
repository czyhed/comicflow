# 角色参考图视觉风格指南

本文档提供不同视觉风格的角色提示词模板，供生成角色参考图时选择。

2026-09-24：下方为历史人工模板，不是当前自动注入规则。项目可选预设以`backend/src/comicflow/production/visual_styles.py`为准；新增“港风武侠胶片”的提炼、精简结构及两次样图观察见[说明](implementation/wuxia-film-style-2026-09-24.md)。不要把下方3D/8K/无颗粒模板叠加到胶片或二维风格。

## 1️⃣ **超高清3D渲染风格** 🔥

**特点**：
- ✅ 8K超高清晰度
- ✅ 游戏角色/电影CG级质感
- ✅ 完美的材质分离（皮肤、头发、布料、金属、皮革）
- ✅ 专业棚拍光照
- ✅ 零胶片颗粒，数字清晰
- ✅ 多角度视图（正面、全身正面、全身背面）

### **提示词模板**：

```
【角色身份定位】
原创角色，三维渲染设定，不参考任何真人演员。

【角色视觉锁｜最高优先级】
[年龄]岁左右的[性别][族裔]面孔，[脸型描述]，[眉眼描述]，[鼻唇描述]，
[表情描述]，[发型发色描述]，[肤色描述]，[体型描述]，[标志性特征]。

【当前造型】
[服装层级详细描述]；[剪裁细节]；[颜色方案]；[配饰道具]；[磨损状态]。

【材质细节】
Ultra-realistic 3D character render，超高清皮肤纹理可见毛孔与细纹，每根发丝
独立呈现自然光泽与流动感，高级面料编织纹理近距离清晰可见，皮革有微小褶皱
与柔和光泽，金属表面镜面反射与指纹痕迹，塑料哑光或光面质感变化，所有材质
物理准确包含次表面散射与菲涅尔效果。

【摄影与构图】
High-end character design sheet，三视图（正面头肩特写 + 全身正面 + 全身背面），
单一人物，自然站姿，T-pose或放松站立，脸部和服装完全无遮挡；85mm等效人像镜头
用于头肩特写，50mm等效视角用于全身，人物比例自然，眼睛、发丝、服装细节清晰
对焦，主体占画面约70-80%，四周留出安全边界，无畸变无透视变形。

【布光与色彩】
Professional studio photography lighting，主光从左前方45度打下，柔和大面积
主光（softbox）塑造面部与身体，右侧弱补光（fill light）消除过深阴影，背后
细微轮廓光（rim light）分离主体与背景，受控阴影保持细节，8K分辨率，干净色彩
分离，明暗过渡细腻如丝，无过曝无死黑，色彩准确饱和度适中，完全去除胶片颗粒，
数字清晰锐利。

【背景与禁止项】
纯色渐变背景（白色、灰色、或单一主题色如红色、蓝色），背景柔和过渡无纹理，
人物轮廓清晰锐利，无其他人物、无文字、无水印、无标签、无边框、无场景道具。

【技术参数】
8K ultra HD resolution，no film grain，digital clarity，ray-traced lighting，
PBR materials，Unreal Engine 5 / Blender quality，AAA game character / cinematic 
CG quality。

【禁止项】
塑料假感、过度柔焦、胶片颗粒、噪点、色偏、过曝、死黑、画面模糊、畸变、
透视变形、线条抖动、色块溢出、画风不统一。
```

## 2️⃣ **电影级写实风格** 🎬

**特点**：
- ✅ 4K-6K高清晰度
- ✅ 真实摄影感
- ✅ 自然光照或电影布光
- ✅ 轻微胶片颗粒（可选）
- ✅ 情绪氛围感强

### **提示词模板**：

```
【角色身份定位】
原创角色，电影级定妆照，不参考任何真人演员。

【角色视觉锁｜最高优先级】
[年龄]岁左右的[性别][族裔]面孔，[脸型描述]，[眉眼描述]，[鼻唇描述]，
[表情描述]，[发型发色描述]，[肤色描述]，[体型描述]，[标志性特征]。

【当前造型】
[服装层级详细描述]；[剪裁细节]；[颜色方案]；[配饰道具]；[磨损状态]。

【材质细节】
真实皮肤质感带自然毛孔与细纹，发丝细节清晰带自然光泽，布料纤维纹理可见，
皮革有真实磨损与光泽，金属有自然反光与氧化痕迹，所有材质符合物理光照规律。

【摄影与构图】
高端角色设定图，单一人物、全身或大半身、正面或四分之三侧身、自然站姿，
脸部和服装无遮挡；50mm等效视角，人物比例自然，眼睛和服装细节清晰对焦，
主体占画面约70%，四周留出安全边界。

【布光与后期】
电影级布光，主光方向为[左前方/右前方/顶光/侧光]，柔和大面积主光、弱补光、
细微轮廓光，受控阴影，干净色彩分离，明暗过渡细腻，保持统一画风；可选轻微
胶片颗粒（Kodak Vision3 500T风格）或数字清晰；禁止塑料感、棚拍过曝、脏噪点
和过度锐化。

【背景与禁止项】
[中性低干扰纯色背景 / 柔和场景背景虚化]，人物轮廓清楚；不得新增人物、文字、
标签、边框或水印。

【技术参数】
4K-6K resolution，cinematic lighting，natural color grading，film photography 
aesthetic，optional subtle film grain。
```

## 3️⃣ **武侠电影风格**（你当前使用的）🗡️

**特点**：
- ✅ 强烈的氛围感与情绪
- ✅ 古装武侠质感（粗布、旧物、雨夜）
- ✅ 电影胶片颗粒感
- ✅ 低饱和度冷色调
- ❌ 清晰度相对较低（因为胶片颗粒+氛围感）

### **提示词模板**：

```
【角色身份定位】
原创武侠角色，不参考任何真人演员。

【角色视觉锁｜最高优先级】
[年龄]岁左右[性别]，[脸型骨相]，[眉眼描述]，[鼻唇描述]，[表情描述]，
[发型发色（含湿发、灰白发等细节）]，[肤色]，[体型]，[标志性特征（刀茧、
疤痕、髭须等）]。

【当前造型】
[头部配饰如斗笠、发冠]；[内层服装]；[外层披风/蓑衣]；[腰带配饰]；[手部
护具]；[下装]；[绑腿]；[鞋履]；[磨损细节（袖口、膝部、下摆泥点等）]。

【材质细节】
粗布质感明显，带[雨水/灰尘]潮湿的重色和贴身垂坠；[蓑衣/披风]纤维粗硬，
表面有[水光/风尘]与暗部积渍；[竹/木制品]的篾纹理清晰；革带和铜扣有生锈、
磨旧的金属粗粝感；[护具]有旧刀疤和棕黑油润磨损；湿发布料贴肤处反光，
不形成大面积高光。

【摄影构图】
单个角色，全身正面，自然站姿；人物位于画面中心，完整呈现头顶[斗笠/头饰]
到脚底[鞋履]；清晰五官，双手自然垂于身侧，[背部道具]不遮挡正面服装；
镜头使用平视中焦段，轻微低角度仰视以突出挺拔感，但不变形面部。

【布光色彩】
写实水墨武侠风，[雨夜冷青色调 / 黄昏暖色调 / 月夜蓝调]，低饱和；主光从
人物[前侧上方/侧面]打下，[冷青灰调/暖黄调]塑造[清冷/温暖]与[潮湿/干燥]；
轮廓用极淡的[蓝灰/暖橙]勾勒，[斗笠/衣物]下保留阴影层次；局部可有一小片
极弱[暖白/冷蓝]从[右下/左侧]补光，暗示[雨夜火光/月光]，但不冲淡整体色调。

【背景禁项】
干净单色[灰蓝/暗红/深绿]渐变背景，无其他人物、无文字、无水印、无现代物品、
无[火光和闪电/多余道具]入画；不添加飞溅[泥水/血迹]、[断刀/兵器]、吊绳或
其他场景道具。

【技术参数】
九十年代港式奇幻武侠电影定妆照，35mm胶片颗粒，Fujifilm Eterna 500T色调，
自然光感，略带颗粒感的质感。
```

## 4️⃣ **日式动画风格** 🎨

**特点**：
- ✅ 清晰锐利的线条
- ✅ 色彩鲜艳或柔和
- ✅ 插画风格材质
- ✅ 适合二次元题材

### **提示词模板**：

```
【角色身份定位】
原创动画角色，日式作画风格。

【角色视觉锁｜最高优先级】
[年龄]岁左右的[性别]，[脸型]，[眉眼风格（如：大眼睛、细长眼）]，[鼻唇风格]，
[表情]，[发型发色（动画化处理）]，[肤色]，[体型]，[标志性特征]。

【当前造型】
[服装描述，使用动画化简化处理]。

【材质细节】
日式动画赛璐璐风格，清晰锐利的线条，色块干净平涂或轻微厚涂，高光用简化
色块表示，阴影用分层色块，无复杂纹理，保持风格统一。

【摄影与构图】
动画角色设定图，单一人物，全身或大半身，正面或四分之三侧身，标准站姿，
脸部和服装完全展示，居中构图，无透视变形。

【布光与色彩】
动画标准布光，主光从前方，柔和阴影用色块分层，色彩鲜艳饱和或柔和莫兰迪色，
明暗分明但过渡柔和，保持动画风格统一。

【背景与禁止项】
纯色背景或简单渐变，无其他人物、无文字、无水印。

【技术参数】
Japanese anime style，cel shading，clean linework，consistent style，
high-quality digital illustration。

【禁止项】
写实质感、3D渲染感、胶片颗粒、线条抖动、色块溢出、画风不统一。
```

## 🎯 **如何选择风格？**

| 你的需求 | 推荐风格 |
|---------|---------|
| **要最高清晰度，类似游戏角色/CG电影** | 超高清3D渲染 ⭐⭐⭐⭐⭐ |
| **要真实感但保留情绪氛围** | 电影级写实 ⭐⭐⭐⭐ |
| **古装武侠题材，强调氛围** | 武侠电影风格 ⭐⭐⭐⭐⭐ |
| **二次元动漫风格** | 日式动画风格 ⭐⭐⭐⭐ |

## 💡 **你的问题：想要超高清质感但题材是武侠**

### **冲突点**：
- ❌ 超高清3D渲染风格（现代感、数字清晰）
- ❌ 武侠电影风格（古装感、胶片颗粒、氛围感）
- ⚠️ **这两种风格本质上冲突！**

### **解决方案A：折中方案** ✅

创建一个**"超高清古装写实"**混合风格：

```
【材质细节】
Ultra-realistic 3D character render with period-accurate costume，超高清皮肤纹理
可见毛孔与细纹，每根发丝独立呈现，古装布料编织纹理清晰可见（粗布、丝绸、
麻布的真实纤维），皮革、竹木、金属的真实材质，保持古装质感但使用现代8K
渲染精度。

【布光与色彩】
Professional studio lighting with period atmosphere，主光柔和，保持[冷色调/
暖色调]氛围，但完全去除胶片颗粒，使用8K数字清晰度，色彩准确，明暗过渡
细腻，既有武侠意境又有超高清质感。

【技术参数】
8K ultra HD resolution，no film grain，digital clarity，period costume with 
modern rendering quality，Unreal Engine 5 historical character quality。
```

**效果预期**：
- ✅ 保留古装武侠服装和道具
- ✅ 使用超高清3D质感（无胶片颗粒）
- ✅ 材质精细（布料纤维、皮肤毛孔、发丝清晰）
- ⚠️ 但会失去"九十年代港片"的怀旧氛围感

### **解决方案B：分开生成** ✅

根据用途选择不同风格：

1. **角色参考图**：使用"超高清3D渲染"风格
   - 目的：让视频生成模型识别角色特征
   - 优势：清晰度最高，细节最丰富

2. **视频生成提示词**：指定"武侠电影氛围"
   - 目的：生成的视频有武侠意境
   - 方法：在视频提示词中加入"九十年代港片风格、35mm胶片颗粒"
