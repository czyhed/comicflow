# 剧本规划适配规则

围绕主角目标保留既有故事、人物关系、事件顺序、对白及说话人，按调用方给出的目标时长、镜头数量和JSON契约拆分。以下规则只用于剧本，不用于故事扩写。

## 字段职责

- 场景的地点、时间、叙事目标、冲突和转折点服从原故事；场景切换有叙事或空间原因。
- visualDescription写景别、机位、人物站位、空间参照与可见光源；cameraMovement只写相机运动，固定机位也明确填写。
- action写一个主要动作；actionBefore、actionMiddle、actionAfter分别写起始姿态、可见过程和完成位置。等待、凝视、倾听可以保持静止，不强行补位移或第二个动作。
- emotion写表演情绪；shotSize写景别；visualStyle使用项目选定风格，与题材分开。中文描述使用简体中文，技术标识只放在约定字段。
- dialogue保留原对白与说话人；narration只写实际要读出的画外旁白；soundscape写环境声和动作音效；music写配乐，无配乐明确写“无配乐”。这四种内容分开，不把音效当旁白朗读。

## 连续性与时长

一次动作要在分配时长内可见地完成。涉及接触、跨越或进入时，写清接触对象、移动方向和最终落点；人物与道具的位置关系在相邻镜头间保持一致。静机、停顿和倾听反应服从原稿。

对白和旁白共用镜头语音预算：单镜合计不超过（时长−1）×4个可发音字符，留出约1秒给动作和反应；调用方给出的逐档上限优先。故事正文不是逐字旁白稿，超出预算时先删减旁白，原对白逐句保留；不要为容纳过长旁白自动延长镜头。总时长和单镜时长以调用方约束为准，不机械套用5秒或15秒模板。

## 竖屏短剧节奏

- 第1镜前3秒给出异常、冲突或悬念画面，不用纯环境空镜开场。
- 相邻镜头的景别不重复，在远景、全景、中景、近景、特写之间切换。
- emotion写成可见表演：眼神、呼吸、手部动作、身体距离，不只写“紧张”“悲伤”等形容词。
- 末镜留下悬念、反转或未完成的动作，作为下一集的钩子。
- 竖屏构图主体居中偏上，画面下方约四分之一留给字幕。
- 5秒及以内的镜头只用一种运镜；跨空间的动作把机位放在终点空间，visualDescription与cameraMovement描述同一机位。

scenes[].shotIds与顶层shots[].id双向一致，每镜只归属一个场景。运镜写cameraMovement，不把镜头要求塞入人物动作。光线、景深和材质与具体媒介匹配，场景示例不能变成全剧统一的霓虹、雨夜或写实摄影默认值。

## 输出边界

输出调用方要求的JSON，不输出Markdown分镜、供应商参考标签或额外说明。角色名称、原始台词、必要画面文字保持来源含义；供应商提示词由视频阶段另行编译。接口校验和真实画质验收仍由应用与用户分别完成。
