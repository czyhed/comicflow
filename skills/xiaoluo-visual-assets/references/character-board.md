# 一次图生图整板

仅用于 character-board 阶段。以已确认主图为唯一人物来源，不重新设计角色，也不复制主图的单人正面构图。

生成一张图片，共四个展示区域：左侧约四分之一为同一角色的正面头肩脸部特写，头顶、发型和五官完整；右侧三个全身视图从左到右依次为正面、严格侧面（90度）、背面（180度）。右侧三列等宽，全身完整，头顶和脚底对齐，身高比例一致，人物之间不重叠。四区都是同一个人，不使用四分之三角度替代侧面或背面。

保持主图的脸型、五官、发型、年龄、肤色、体型、服装层级、配色和已有配饰。只改变观察方向；背面保持合理的同一服装结构，不新增装备或夸张装饰。

画布使用模型配置的实际尺寸，四个区域在画布内清晰排列，不在提示词中提升分辨率。中性纯色背景、均匀光照、自然站姿、全身留安全边界；保留项目画风与材质，脸部特写仅放大主图的同一身份，不重新设计五官。不要文字、标签、分格线、水印或剧情场景。

输出只作为候选供用户核对身份、角度与完整性。不能因请求成功就认定画质合格或自动用于视频；不合格时保留记录，不自动重生。
