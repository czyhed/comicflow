# 角色主图提示词编写

用途是为后续图生图和视频提供可辨认的角色身份参考。遵循调用方指定的JSON字段；不要输出本文件的说明、案例或未请求字段。来源与取舍记录在`docs/implementation/character-prompt-source-research-2026-09-20.md`，本文件是ComicFlow适配规则，不是上游模型官方模板。

## 按本次用途输出

- 完善设定：只返回选中的外观、服装、性格字段；故事和出场镜头用于确认身份与时代，不把镜头气氛当成永久外观。
- 润色主图：只返回referenceImagePrompt。现有外观和服装是事实约束；不擅自增添年龄、痣、疤痕、装备或换衣服。设定不足时保留已有信息，不用示例角色替换。
- 完整草稿兼容调用：返回指定的四个字段，图像描述与返回设定一致。

## 主图组织顺序

写成自然中文，通常约200—500字足够；这是编写建议，不得为了凑字数重复要求或截断必要身份事实。

1. **角色锁与风格**：说明这是单一角色的全身正面参考主图；复述已有脸型、眉眼、发型、肤色、体型和辨识特征。项目选定风格优先，没选风格时保留用户明确的画风，不默认所有角色都是真人。
2. **服装与材质**：保留层级、领口/袖口、主辅配色和既有配饰。选择实际存在的两三处材质说明表面怎样受光，如棉布哑光与细密织纹、皮革柔和反光与缝线、金属小面积受控高光。没穿丝绸就不加丝绸，没戴金属就不加金属。
3. **形体与构图**：一人自然站立、表情放松，双手自然下垂且不挡服装，头顶至鞋底完整入画并留少量边界。面部与服装同时清楚，正常透视，不用大头特写、广角夸张或浅景深虚化来冒充质感。
4. **光影与色彩**：光影表达服从所选媒介。写实和三维可用柔和主光、暗侧补光和明暗渐变塑造体积；二维、厚涂、水墨使用该画风的色块、笔触或墨阶。发梢和衣缘与中性背景适度分离，肤色/衣色及暗部五官可辨；不要为了统一布光抹掉项目画风。
5. **背景与限制**：简洁中性纯色背景，无新增人物、文字或水印；不复刻剧情的烟雾/雨夜/霓虹/遮挡，不混入运镜、对白、时间轴或三视图拼版要求。

## 质感必须匹配媒介

- 真人写实：肤色层次自然、少量细微肤质、发丝与衣料有层次；避免磨皮蜡感、过锐颗粒，不能要求每个毛孔夸张可见。
- 二维动画：沿用项目的描线和上色方式，线条与色块边缘稳定；仅在项目采用赛璐璐时使用分区阴影，不能强加给无描边或平涂画风。不加真人毛孔或照片织物贴图。
- 三维动画：轮廓体积、发束分层、布料厚薄与接缝、受控材质高光、自然接触阴影；不能禁止一切三维感，也不能套用真人照片皮肤。
- 厚涂：以笔触和冷暖色面塑造体积，脸部焦点清楚；水墨：墨阶与留白、关键轮廓可读；漫画：明确轮廓和图形化阴影。只选与项目匹配的一套表达，不混成写实+水墨+赛璐璐。

## 输出前自查

人物事实与所给字段是否一致；是否只有一个画风、一套站姿和一套照明；服装材质是否真实存在；脸部和全身是否同时可读。移除大师级、顶级、杰作等重复赞美词及无必要的相机品牌、镜头参数、平台专用旗标，不声称提示词里的分辨率能改变API实际尺寸。

这是提示词编写，不是图片质量验收。不能声称“保证不变脸”或“必出高质感”；生成结果仍需用户检查。
