## Context

见 proposal.md。来源版本及完整评估见 docs/research/itovideo-drama-base-assessment-2026-10-13.md。当前首版范围以用户最新的前端演示目标为准，完整漫剧生成适配交接作为后续路线。

## Goals / Non-Goals

**Goals:** 保留原页面和真实交互，通过预置角色、剧本及可播放示例媒体展示画布到后期的路径。项目状态保存于隔离 PostgreSQL，媒体由本地 S3 存储提供。

**Non-Goals:** 真实付费生成、旧数据迁移、线上替换、完整多角色生产流水线、调度器重写。

## Decisions

1. 整体副本沿用 React/Vite + FastAPI/psycopg 和原 API；独立目标不适用原 ComicFlow ADR 0005 的 ORM/Worker 迁移要求。后续正式替换另记决定。
2. 演示模式显式配置；模型提交被后端阻断，预置媒体不标为新的供应商输出。合成和字幕导出继续走原 FFmpeg 后端。
3. 复用用户已有的两张武侠角色图片，制作注明示例的动态预览；画质不作为真实模型效果承诺。品牌暂用 ComicFlow 漫剧，保留原布局与样式。
4. 种子数据显式初始化且幂等，不在每次启动覆盖编辑。例子包含画布项目和完成逐镜制作的 Studio 项目，以原后期交互承接。

## Risks / Trade-offs

- 本机依赖与原锁定版本 → 使用锁文件安装，先完成原基线构建。
- 独立副本夹带运行配置 → 清空覆盖副本环境配置，只指向 loopback 隔离服务；历史日志及 IDE 文件不纳入交付。
- 商品 Studio 准备阶段仍未完整漫剧化 → 首版明确以已准备的示例进入制作/后期；不宣称任意故事真实生成完成。
- 静态图运动预览 → 显式注明示例动画，不混同模型生成动态漫剧。

## Migration Plan

仅本地独立运行，端口 5188/9021 与独立 PG/MinIO；原项目不切换。回退关闭新服务即可，保留用户编辑的独立卷。
